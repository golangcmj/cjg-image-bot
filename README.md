# cjg-image-bot

AstrBot 图片插件，当前支持两个命令：

- `/生图`：严格文本生图（text-to-image）
- `/改图`：基于消息可解析图片做编辑，仍走 `/v1/images/generations`

## 命令说明

### `/生图`

示例：

```text
/生图 二次元少女，白发蓝瞳
```

行为：

- 只提交纯文本描述
- 输入中的控制片段（如 `data:image/...`、`[[强度=0.3]]` / `[[strength=0.3]]`）会在提交前剥离

### `/改图`

示例：

```text
/改图 请改成赛博朋克风格 [[强度=0.3]]
```

行为：

- 文本描述不能为空；去掉控制片段后若为空，返回 `请输入改图描述`
- 图片来源优先级固定：
1. 当前消息第一张图片
2. 回复消息第一张图片
3. 第一位被 @ 成员头像
- 每个来源只尝试第一张图片，不会在同一来源继续尝试第二张
- 若某来源的第一张不可转换为有效标准 data URI，才会回退到下一来源的第一张
- 三个来源都不可用时返回 `未检测到图片`
- 强度别名支持中文优先写法 `[[强度=0.3]]`，会归一化为 `[[strength=0.3]]`
- 最终仍复用同一 generation 请求与回图流程，不暴露后端上传细节

## 配置项

- `openai_api_base`
- `openai_api_key`
- `selected_model_id`
- `default_i2i_strength`（默认 0.35）
- `strength_keyword`（默认 `强度`）
